# Disease Prediction Project

This project is an educational machine learning study that aims to predict diseases based on symptoms using structured medical data.

The purpose of the project is to understand:
- Data preprocessing
- Model training
- Overfitting problems
- Data leakage risks
- Evaluation of machine learning models

This project was developed for learning and experimentation purposes.

---

## Dataset

The dataset contains symptom-based features and a target column:

- Each column represents a symptom.
- Values are binary (0 or 1).
- The **prognosis** column represents the disease label.

Example:

| itching | skin_rash | headache | prognosis |
|--------|--------|--------|--------|
| 1 | 1 | 0 | Fungal infection |
| 0 | 0 | 1 | Migraine |

Dataset files:
disease_prediction/data/Training.csv
disease_prediction/data/Testing.csv
